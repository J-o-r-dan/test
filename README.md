# fredrin

Created with [Fredrin](https://fredrin.com).

This project runs on local git. It has no remote, and it does not need one —
branches, worktrees, diffs and merges are all local.

## About page

`index.html` is a self-contained, dependency-free personal About page. Edit the
highlighted `TODO` placeholders (name, projects, contact details), then preview by
opening the file in a browser or running `python3 -m http.server`. It can be
published as-is on any static host.
